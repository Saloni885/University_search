
# University Search Application

A simple web application to search universities by country and state using the Hipolabs Universities API.

## Features
- Search universities by country.
- Filter results by state.
- Fetch university data using Axios.
- Display matching universities dynamically.

## Technologies
HTML, CSS, JavaScript, Axios, REST API.


## API
[Hipolabs Universities API](https://github.com/Hipo/university-domains-list)
